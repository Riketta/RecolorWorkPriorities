# Recolor Work Priorities

The work tab's priority colors are shifted one tier up: priority 2 wears
priority 1's green, priority 3 wears priority 2's yellow, and priority 1 gets
a new cyan. The low-skill warning border appears from skill 3 and below
(vanilla: 2 and below); both the colors and the threshold are configurable.

## What it does

- Recolors manual work priority numbers: 1 cyan, 2 green, 3 light yellow,
  4 grey by default - all four colors configurable in mod settings.
- Relabels the drawn priorities to A / 1 / 2 / 3 (top tier letter is
  customizable); real priority values stay 1-4 underneath.
- Moves the low-skill warning border (and its tooltip warning) one tier up,
  with a configurable skill threshold.
- Works with the vanilla work tab and Fluffy's Work Tab (detected
  automatically; its gradient colors are shifted the same way).

Requires the Harmony mod. Works with all DLC and mods, safe to add or remove
at any time.
